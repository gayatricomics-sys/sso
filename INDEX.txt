TEST COVERAGE
================================================================================

STAGE 1: RECONNAISSANCE (13 tests)
  • Endpoint & metadata discovery
  • Certificate hygiene
  • Trust relationship mapping

STAGE 2: TOKEN ANALYSIS (32 tests)
  • XSW 1–8 (all signature wrapping variants)
  • JWT crypto (alg=none, HMAC, missing claims)
  • SAML manipulation (audience, issuer, NameID)
  • Microsoft Entra ID (tid, idtyp, ver)

STAGE 3: FLOW LOGIC (25 tests)
  • redirect_uri validation (7 variants)
  • state parameter bypass (CSRF)
  • Consent/prompt manipulation
  • SAML flow logic
  • ADFS/WS-Federation
  • Microsoft tenant confusion

STAGE 4: SESSION/LIFECYCLE (20 tests)
  • Single Logout (SLO) validation
  • Session timeouts
  • Token revocation
  • Cookie flags (Secure, HttpOnly, SameSite)
  • Token storage (localStorage vs. cookies)

TOTAL: 90 test cases
AUTOMATION RATE: 53% automated, 47% manual verification

CRITICAL VULNERABILITIES DETECTED
================================================================================

This extension will find:

CRITICAL:
  ❌ alg=none JWT (no signature)
  ❌ idtyp=app on user endpoint
  ❌ Token in localStorage
  ❌ Assertion accepted without signature

HIGH:
  ⚠️ Missing state parameter (CSRF)
  ⚠️ HMAC alg confusion
  ⚠️ HttpOnly flag missing
  ⚠️ XSW 1–8 variants accepted
  ⚠️ Microsoft tid missing

MEDIUM:
  ⚠️ Missing exp/aud/iss claims

================================================================================
QUESTIONS?
================================================================================

Q: Do I need to enter credentials manually?
A: No. You login normally through Burp Proxy. Extension watches & captures tokens.

Q: Will active scans burn credentials (like lockout attempts)?
A: No. Active scans only generate variants. Manual tests in Repeater do actual sends.

Q: How long does full assessment take?
A: ~2–4 hours: 30 min setup, 1.5 hrs testing, 1 hr verification, 1 hr reporting.

Q: Can I use this on production?
A: Not for active scans. Use staging/test environment. Passive scans are read-only.

Q: What if extension doesn't load?
A: Check Jython 2.7 JAR via Extender → Options. See INSTALLATION_GUIDE troubleshooting.

See DELIVERY_SUMMARY.md for more Q&A.
